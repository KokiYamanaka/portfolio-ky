Transform: Min-Max Scaling

•Definition: resize numbers so every column plays on a fair, even field

•Machine learning trains more easily on resized inputs

•Problem: columns such as age and price differ hugely in scale

•Solution: rescale every column to the range 0 to 1

Linear Regression Basics

•Multiply each feature by a “weight” and add them up to predict the output

•The larger the weight, the greater that feature’s influence

•Training means finding the weights that make predictions accurate

Math score formula (3 features)

Math score = baseline

+ weight 1 × study hours

+ weight 2 × attendance rate

+ weight 3 × homework rate

Linear Regression in a Bit More Detail

•Reading a weight: the change when a feature rises by 1, other things equal

•Error: the gap between predicted and actual scores; smaller is better

•Training: find the weights that minimize error (least squares)

•The better the features, the higher the accuracy (today’s exercise)

Reading the weights (example)

Study time +1 hour → predicted score +1.5 points

Attendance rate +0.1 → predicted score +3 points

Error example

Actual score 80, predicted 78 → error of 2 points
